# اختبارات «سباق الحروف بالفتحة» داخل التطبيق

تشغيل خادم ثابت من جذر المشروع ثم: `BASE=http://localhost:8123 NODE_PATH=$(npm root -g) node tests/reading-race/<الملف>.js`

- `play.js <letter-id> <wrongClicks>`: سباق كامل لحرف واحد (٥ جولات) مع خطأين في الجولة الأولى؛ يطبع أحداث الصوت (تشغيل/انتهاء) لفحص التداخل والفاصل ~٢٤٠ مللي.
- `manual.js`: ضغطة «اسمع الحرف» أثناء تأكيد الصحيح.
- `nav.js`: الخروج وإيقاف الصوت وزر الرجوع وسجل المتصفح والعودة لشاشات الألعاب القديمة.
- `stars.js`: النجوم المجمّعة داخل اللعبة لا تغيّر التخزين ولا رصيد الطالب.
- `layout.js`: ٧ مقاسات (٣٢٠ → ١٩٢٠) تأكد من ظهور البوابات داخل الشاشة وعدم وجود أرقام لاتينية.
- `touch.js`: لمس حقيقي (محاكاة) والإجابة الخاطئة ثم الصحيحة.
- `engine-compare.js <portA> <portB>`: مقارنة بصمة محرك السباق القديم بين نسختين (يحتاج خادمين).
كلها محاكاة متصفح؛ لا تغني عن اختبار السبورة الحقيقية.
